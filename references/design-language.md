# 视频设计语言（默认版式系统 · 40+ 高可读演播室科技感）

以现代信息设计的秩序为骨架，默认面向中国 40+ 中年观众，做成“权威新闻/财经纪录片 × 现代科技演播室”的高可读视觉。
**适用条件（2026-09-02 修订）：这是"用户没有明确受众与风格要求时"的默认，不是对用户明确风格的覆盖**——
用户点名了风格（综艺感/赛博/纸面手绘/某个品牌的调性…）就按用户的来，整套替换；
但除非用户明确撤销，**1.5× 字号硬底线与交付头尾禁转场**对所有风格都成立。替换的也必须是一套完整 token，
不允许逐场景随手取色。无明确要求时，新片开工先按本文件定 token，再落成工程里的 `theme.ts`。

独立素材模式先读 [cger-broll-standard.md](cger-broll-standard.md)：该模式使用每条不同的生成背景和统一黑银朱红色板，覆盖下述纯色交替/按幕背景默认；取消主标题下的中间滚动说明层。

## 0. 40+ 观众默认画像与“炫酷”的定义

- **先看懂，再觉得酷**：一屏一个结论，主标题 8–12 个汉字/行、最多 2 行；重要数字和关键词必须大到一眼扫中。
- **熟悉的权威感**：借鉴新闻演播室、财经纪录片、重大项目发布片的秩序——深海军蓝/墨黑舞台、暖白证据卡、
  一个高饱和红或金色强调。不要把“中年”理解成复古、土味或满屏金光。
- **炫酷靠宏观动作**：大数字砸入、机械锁定、地图路线推进、聚光追焦、实物证据推近、纵深相机和强节奏硬切；
  不靠紫蓝霓虹、小字 HUD、glitch、扫描噪点、密集粒子、连续抖屏或英文装饰词。
- **信息优先级显式**：主结论 > 证据/数据 > 来源。40+ 观众不应通过辨认细灰字或猜图标来理解主旨。
- **节奏留出阅读时间**：重要结论落定后至少 hold 1.2s；每 1.5–3s 一次强视觉事件，避免每 0.2s 换一件小东西。

核心气质：
1. **内容即主角，版式退后**——装饰服务于结论；靠大色块、聚光、纵深和底色切换分段，不靠花边堆砌。
   （§1.1 的背景资产按幕启用，不逐镜随机换。）
2. **全片只有一个强调色**——所有"看这里"信号（关键词、划线、标注、CTA）用同一个 accent。
3. **全系统只有一个投影**——只给"证据素材"（截图/照片/实拍）用，卡片和文字永远不加投影。
4. **底色交替就是章节感**——浅底 ↔ 深底的幕间切换本身是分隔符（对应 env.tsx 的 ACTS 分幕表）。

## 1. 色板

双模式：默认按**深海军蓝/墨黑舞台 + 暖白证据幕交替**。钩子、反转、数据峰值和收束用深底；
解释、清单和真实证据用暖白浅底。若整片只用一种底色，必须在 SHOTBOOK §0 写明理由。

| token | 浅底模式 | 深底模式 | 用途 |
|---|---|---|---|
| canvas | `#fffaf2` | `#071426` | 主画布：暖白 / 深海军蓝 |
| canvas-alt | `#f2eadc` | `#12233b` | 交替幕底色（相邻幕之间的微阶差） |
| ink | `#111111` | `#ffffff` | 标题与正文 |
| ink-muted | `#4a4a4a` | `#cfd8e6` | 次要信息、来源行；不用低对比浅灰 |
| hairline | `#cfc7ba` | `rgba(255,255,255,0.24)` | 卡片 2px 线（40+ 受众不使用若隐若现的 1px 发丝线） |
| **accent** | `#e53935` | `#ff5a52` | **默认唯一强调色**：关键词、划线、标注引线、图表主系列；也可整片换成暖金，但红金不可同时抢主角 |
| positive / negative | `#248a3d` / `#d70015` | `#30d158` / `#ff453a` | **只进图表和涨跌标注**，不做版式色 |
| marker | `#FFE949` @60% multiply | 同左（screen 模式） | 只给荧光笔扫词 |

红线：accent 之外不允许出现第二个"看这里"色；语义色出现在正文/标题上即违规。
深底默认是**深海军蓝到墨黑**，用聚光和大色块建立纵深；禁止紫蓝霓虹、细密 HUD 网格和多色辉光。
`template/motion-systems/theme.ts` 已改为中性稀疏网格；生产项目仍必须从本片 token 派生，不得自行恢复青色科幻网格。

**浅底的"能量"手法**（深底辉光/曝光语法在白底上无效，替换为）：
层级与重音靠底色阶差、发丝线、accent 描边/换色、punch 缩放、唯一投影；
环境层 = 极轻 vignette（`rgba(0,0,0,0.06~0.12)`）+ 轻微暗压脉冲（重音时全场 2~3% 变暗一拍，方向与深底曝光相反）；
扫光改为 3~4% 的冷暖微偏移；深色代码面板/终端窗按"深 tile 卡片"处理，自带层级无需辉光。

浅底两条实测红线（deepseek-harness-v2 r3 评审量化确认）：
- **转场白闪在浅底失效**：白底基线亮度 ≈237，再叠 0.34 白闪无处可涨（深底同表有 +29 亮度峰，浅底实测无峰）。
  过曝翻页式在浅底一律反向做**暗压闪**（切点一拍 6~10% 全场变暗 3~4 帧再回弹），或 2~3 帧纸白硬切到 255。
- **dim 件禁止再叠 opacity**：`#7a7a7a` 在白底只有 4.29:1 余量，叠透明度必掉出可读区
  （实测字幕未读词叠 opacity 后 2.06:1）。未读态/来源行/图例一律用 dim **实色**，要更淡就换更深的底不动字。

### 1.1 背景菜单（2026-08-27 用户比选定版）

默认幕底仍是上表的 canvas / canvas-alt **纯色交替**；以下三款是**可选背景资产**——
按幕启用、在 SHOTBOOK §0 声明用在哪几幕，禁止镜头级随手换背景。
都是静态底，"活"仍由 G4 环境层（呼吸 vignette + 扫光）叠加，两边不冲突。
（选型记录：11 款候选同前景比选，线性微渐变/单色 glow/噪点 grain/双角 tint/aurora/星点/压暗素材底落选。）

| 款 | 配方（1920×1080） | 使用条件 |
|---|---|---|
| **稀疏工程网格**（浅底） | 底 `#fffaf2`；2px 线 `rgba(17,17,17,0.055)`，格距 108~144px；整层套径向遮罩 `radial-gradient(120% 100% at 50% 40%, #000 30%, transparent 85%)`——网格只在中心可见、向四周隐去 | 只用于数据/工程题材幕。文字密集镜头和产品 UI 镜头不用，不叠 HUD 标签。动态版即 env.tsx 的 GridField（记得进 G2 视差层） |
| **演播室斜切光带**（深底） | 底 `#071426`；用唯一 accent 做一条 8–14% 透明度的大角度斜切光带，叠一团随主体走的白色聚光；不加第二彩色光 | 钩子/最大反转整幕。第一帧可直接显示该背景，但不得拿光带做全屏开场擦除；结尾也不做扫屏退场 |
| **居中追光 + vignette**（深底） | 底 `#131317` + 白色聚光 `radial-gradient(65% 70% at 50% 42%, rgba(255,255,255,0.10), transparent 65%)` + vignette `radial-gradient(140% 130% at 50% 50%, transparent 55%, rgba(0,0,0,0.55) 100%)` | 金句幕/反转幕的舞台感。光斑圆心跟**主体落位**走（不必居中）；自带 vignette，与 G4 呼吸 vignette 叠加时收拢其一，别双重压暗；白光不构成第二强调色 |

落地：三款写进 `theme.ts` 当具名 token（如 `bg.grid` / `bg.mesh` / `bg.spotlight`），场景整幕引用。

## 2. 字阶（2026-09-02 硬规则：旧基准 × 1.5，横竖屏都不得低于）

**字体定版（2026-09-10）**：全部可编辑中文、西文、数字与标签统一使用阿里巴巴普惠体 3，本地字体为 `assets/fonts/puhui-regular.ttf` 与 `puhui-bold.ttf`（相对 skill 根目录）。标题/强调使用真实 Bold 700，正文/来源使用 Regular 400；下表字重及旧模板中的 600/800 一律映射到这两个真实字重，字号下限不变。等待字体加载后渲染，不依赖系统回退或合成粗体；真实截图原生字除外。**数字一律 `font-variant-numeric: tabular-nums`**（计数不跳宽）。

| token | 字号/字重/行高 | 用途 |
|---|---|---|
| hero | 192 / 800 / 1.05 | 全片 1–2 次的英雄大字（钩子数字、金句核心词） |
| display | 132 / 800 / 1.08 | 幕标题、章节卡编号 |
| headline | 96 / 800 / 1.15 | 场景内小标题、图表标题 |
| tagline | 72 / 700 / 1.2 | 卡片标题、人名条主行 |
| body | 66 / 600 / 1.4 | 卡片释义、引言正文 |
| subtitle | 66 / 700 / 1.3 | 横屏字幕；竖屏另见 §5 |
| caption | 48 / 600 / 1.35 | 标注、图例、头衔行 |
| micro | 36 / 600 / 1.3 | 来源行、法务行；禁止承载关键结论 |

- 字重阶梯以 **600 / 700 / 800** 为主；关键中文禁用 300/400 细字。正文需要长段落时也不低于 600。
- 西文/数字在 display 以上可加 `letter-spacing: -0.02em`；中文字距 0，不模仿西文负字距。
- 一屏文字层级 ≤3 级；释义超过 2 行就该拆成两拍。
- **hero 造型一屏一个**（2026-08-28 用户定版）：同屏多个数字/大字时只有一个上 hero/display 档造型
  （大字号/色块/换色），其余降 body/caption 行内注——三个数字三种 hero 造型互相抢戏读作凌乱（v4 实测反例）。
- **字号按手机验收**：默认竖屏成片缩到 **390px 宽**复看，每行能读才过（桌面全屏预览不是验收标准）；
  排不下时**删次要文案 / 缩短措辞 / 拆成下一拍**，不得降低本表字号，禁孤字行。
- 旧卡片、旧工程或外部模板的字号全部乘 `TYPE_SCALE = 1.5` 后再排版；不允许以“模板放不下”为理由保留旧字号。

## 3. 间距 · 圆角 · 投影

- **间距基数 16px**：16 / 24 / 32 / 48 / 64 / 96 / 160。内容与画布边缘 ≥96px（action-safe），标题类 ≥160px（title-safe）。
- **横屏内容主列 ≤1440px 居中**；满宽只留给全出血素材和背景层。
- **圆角语法**（三档，不混用）：`12` 小件（chip/标签）· `28` 卡片（截图卡/信息卡）· `pill` 行动件（按钮/进度）。全出血幕 = 0。
- **投影只有一个**：`0 12px 60px rgba(0,0,0,0.22)`，只给"落在底上的证据素材"（截图/照片/手机壳）。卡片层级靠 hairline + 底色差，文字永不加投影（字幕描边是可读性手段，不算投影）。深底模式的辉光（glow）属于 L4 动效层，由动效系统管，不写进版式。

## 4. 运动 token（版式的时间维度）

| token | 值 | 说明 |
|---|---|---|
| enter | 0.2–0.8s | 入场；`power3.out` 起步 |
| exit | 0.15–0.5s | 出场永远比入场轻 |
| punch | 5–9 帧 | 重音；scale +0.02~0.04，衰减包络 |
| press | scale 0.95 一拍 | "被点击/盖章"反馈 |
| overlap | 12–16 帧 | 转场交叠（transitions.tsx） |
| camera | `inOutSine` | 相机曲线唯一缓动 |

**交付头尾不是 transition token 的使用位置**：第一帧直接显示已建立的画布与至少一个完整可读主视觉；
最后 12–18 帧保持最终构图可读，只允许环境层极轻呼吸，不允许全屏遮罩、淡入淡出、wipe、whip、红/黑幕或转场音效。
内部镜头边界才使用 `overlap` 与转场库。独立素材的每一条都执行此规则。

**禁用两种"做旧"微抖（用户定版偏好）**：手绘线条的 line boil（画完后 8~12fps 换形变帧的"沸腾"）
和贴图元素的 stop-motion 定格抖动（steps 时序随机偏移）一律不做——画完/落定的元素保持干净静置。
手作感由形状本身（歪斜、弧度、白边、胶带、投影）表达；hold 期的"活"只走系统性通道：
相机漂移、Live idle 双正弦、环境呼吸（这些是连续缓动，不属于此禁项）。

## 5. 字幕规范（按画幅）

| | 竖屏 1080×1920（默认硬规则） | 横屏 1920×1080（仅用户明确指定） |
|---|---|---|
| 位置 | 底部居中，bottom 350px（避 UI） | 底部居中，bottom 100px |
| 宽度 | maxWidth 90% | maxWidth 66%（≈1270px） |
| 字号 | 72 / 700；>15 字最低 69 | 66 / 700；>24 字最低 57 |
| 样式 | 白字 + 黑描边（整句硬现） | 浅底：ink 直排无描边；深底：白字 + 6px 黑描边 |
| 组件 | components 版（整句硬现） | motion-systems/Subtitles.tsx（素排版） |

**素排铁律（2026-08-27 用户定版）**：底部跟读字幕**不加任何动效**——整句硬现、整句硬走，
无淡入淡出、无逐字上色、无 pop、无浮动。唯一例外是 `keyword-pop-highlight` 关键词弹出，
且全片**最多 3 次**，除非用户明确要求更多（组件的 `keywords` prop 内建此上限自检）。

**字幕无标点（2026-08-28 用户定版）**：底部跟读字幕不含任何句读/引号/括号/破折号/省略号——
句号问号一律去掉，长句的语气停顿靠**拆卡**表达（按停顿把一句拆成多张字幕卡，每卡一口气），
问句情绪交给口播语气。唯一例外：数字/型号中间的半角点号（`v0.1.1`、`83.8`）保留。
另：画面文字与字幕不得整句相同——画面文字是 ≤12 字的提炼（cinematography.md §4.5）。

常驻件（logo/吉祥物/进度条/**人物头像章·抠人角标**）：横屏放**左下或右下皆可**（无平台 UI 侵占）；
竖屏必须左下。人物角标同守此条：chip 圆心必须落在画面**下 1/3 带**内，不许飘到中高位。

## 6. Do / Don't

**Do**
- 每幕开工先问"这幕的底色是哪档"——底色切换代替章节分隔线。
- 关键词强调 = accent 换色 + punch，一句最多一个。
- 证据素材（截图）永远带白边卡 + 唯一投影 + 轻微 Ken Burns，像"摆在桌上的实物"。
- 数字用 tabular-nums + hero/display 字阶，单位用 caption 阶后置淡入。
- 每镜全程保留至少一个空象限（排版预算全表见 cinematography.md §4.5）。
- 用大中文、真实人物/证据、地图/时间线/大数字和演播室聚光建立 40+ 观众熟悉的权威感。
- 第一帧直接可用，最后一张画面读完再结束；内部转场炫酷，成片头尾干净。

**Don't**
- 不出现第二强调色；不给卡片/按钮/文字加投影；不用装饰渐变（氛围来自素材和 env 层）。
- 不在同屏混用两种圆角语法；不让文字压到 action-safe 以外。
- 中文不加负字距；正文不用 300/400 细字，也不靠 900 黑块堆满一屏。
- 画面文字不整句照抄字幕/口播；同屏不出现第二个 hero 造型的数字/大字。
- 不用小字 HUD、密集 chip、装饰性英文缩写、紫蓝霓虹 glitch 或快速碎闪冒充科技感。
- 不在开头加全屏揭幕，不在结尾加红幕/黑幕/淡出/缩放退场或 transition SFX。
