# C哥独立视频素材制作标准

2026-09-10 用户定版。适用于独立剪辑素材、批量 B-roll，以及“按前面的标准重新做”。这是已确认的制作默认；用户后续明确修改时按新要求。与旧版默认纯色幕底、系统字体、说明文字动效冲突时，本文件优先。

## 前景表现与底部声明（2026-09-10 用户固化）

- 保留既有 AI 场景背景、黑银朱红背景材质与原背景动效；调整动画组件时只修改前景，不改成整屏纯 UI。新话题仍按下文生成独立背景。
- 前景沿用样片方向：烟色半透明玻璃、银色金属、克制的浅冰蓝强调，清楚的连接关系与有起止的动作。科技感来自材质、结构、纵深与动作因果，避免难懂的抽象几何和无意义漂浮。
- 每条顶部必须是“主标题＋二级标题”两行（2026-09-10 后续修订），两者各占一行，首帧完整在场并保持到末帧。主标题≥96px，二级标题≥72px，阿里巴巴普惠体3 Bold 700；默认主标题白色、二级标题浅冰蓝。二级标题补充对象、范围或短结论，不只把主标题机械换行，不加第三行阶段标题。流程节点文字和必要的对象/动作短标签可以保留；贴近对应对象，避开组件完整运动路径，不堆长句讲解。
- 整批交替安排“文字流程示意 → 具体动作演示 → 文字流程示意 → 具体动作演示”。图文类用节点、箭头、路径推进讲清关系；动作类用可辨识对象的阻挡、转移、开合、反馈等过程讲清变化，必要时配短标签。每类内部也要变化构图与机制，不能所有图文都做三张卡片、所有动画都重复一个动作。
- “AI 生成示意”能省则省，默认不添加。确有必要的其他声明或示意提示统一放在屏幕最下方、水平居中；竖屏默认距底48px、36px字号，不放标题下第三行，不与主信息混排。没有声明时不保留占位。来源记录仍保留在制作资料中，不把示意画面冒充真实现场或官方背书。
- 以上作为后续默认，不必每次重新确认相同风格；用户要求换风格时先出案例再批量实施。仅要求更新 skill 时只改规则，不修改或重渲染已有视频。用户要求只补二级标题、其他不变时，只修改顶部标题区，保留背景、前景动画、动作节拍、音效、时长及其他标签，更新对应预览与交付包。

## 交付模式与流程

文案 → 核实关键事实 → 按语义拆分素材 → 独立背景设计与生图 → SHOTBOOK → 统一字体和图层系统 → 分镜动画 → 渲染 → 成片复核 → 打包。

- 沿用本套标准时默认 20 条、每条 8 秒、1080×1920、30 fps；用户指定数量/时长优先。每条有独立叙事，不把同一模板只换标题凑数。
- 无配音仍可直接做素材，按相对秒规划视觉节拍；不要求补配音，不生成虚假的字级时间戳，不声称声画逐字对齐。beat_lint 与人声掩蔽检查标为不适用，不能伪报通过。有配音才运行主流程的时间戳及混音检查。
- SHOTBOOK 每条记录：对应口播、单一结论、背景主体/场景、背景文件、表现类型（图文流程/动作演示）、主标题与二级标题（顶部固定两行）、下方流程或动作因果链、三个以上关键状态、扫光层序、音效、事实属性（证据/示意/未来设想）。

## 每条背景不同，整体风格相同

- 每条新生成一张独立背景；新文案整批重做时，不复用上一话题底图。裁切、镜像、换色和微调角度不能充当新背景。
- 默认背景视觉：炭黑/黑曜石底、拉丝银金属、烟色玻璃、朱红单一强调色、电影感定向光。统一色板、材质和光线语言，按语义更换真实主体、环境、机位与空间结构。
- 先列全批背景清单，避免连续出现同一种机柜/走廊。构图上方约 40% 留安静深色空间，下方为主题实物；无需每条同一机位。生成图不含文字、品牌标志、伪造截图。
- 所有栅格图片生成/编辑只用 Codex 内置 image_gen，不调用第三方生图模型或脚本。参考编辑前查看图片，通过 referenced_image_paths 传入本地参考；无本地路径才使用最小最近图片数。
- 首张建立材质与光色参考，后续保持风格但明确要求不同主体和场景。保存原图、逐条提示词与资产映射；哈希检查重复，另看总览判断视觉近似，不能只凭哈希不同验收。
- 底图只做固定锚点的单向缓慢放大，例如 8 秒 scale 1→1.035；不往返漂移、不抖动。动态由独立前景完成。生成背景是示意，不能冒充官方现场；真实网页证据仍用实际截图。

## 字体与文字层：取消滚动说明

- 全部可编辑文字统一使用阿里巴巴普惠体 3，包括中文、英文、数字、图表与来源；标题/重点使用真实 Bold 700，正文/来源使用 Regular 400。字体位于本 skill 的 assets/fonts/puhui-{regular,bold}.ttf，复制到工程并本地注册、等待加载完成后渲染；不依赖系统回退或浏览器合成粗体。
- 保留既有字号下限：hero 192、display 132、headline 96、tagline 72、body 66、caption 48、micro 36。字重采用本文件 400/700，不沿用旧模板伪 600/800。排不下先缩短文案/拆镜，不能缩字体或整体 scale。
- **删除顶部两行标题区以外的滚动/轮播/分阶段说明文字层**，即用户红框中“省下制作费 只是第一步”这类中间正文。不是暂停滚动后保留它，也不能换成打字机、逐句淡入或长段说明绕回同一层。固定的第二行二级标题不属于此禁令。
- 上方固定两行：第一行主标题、第二行二级标题；必须测量两行文字宽度，分别单行显示，不能自动换成三行，也不能只留一行。二级标题静态呈现，不滚动、不轮播、不另起中间说明层；声明按本文件最新修订默认省略，必要时置于底部居中。下方动画按理解需要添加对象和动作短标签，可按需要附数值，标签贴近对应对象，不堆长句讲解。
- 删除说明层后重新分配空间，扩大主动画有效面积，不保留空槽、不向底部字幕与平台控件安全区挤占。
- 不按固定字符数硬拆英文品牌/单词或数字单位；人工明确换行点，测量真实字体边界。390px 手机宽度复看，标题、来源、标签全阶段不得重叠或截断。
- 本禁令针对素材中间说明层，不删除用户明确要求的成片跟读字幕；跟读字幕仍用整句硬现、无动效规范。数字计数器可用，不能混淆为禁用数字动效。

## 下半区动画：有趣、清楚、有结果

- 下方是主叙事舞台。图文流程类用节点与路径的推进突出关系，动作演示类用可辨识的物体动作表达机制；不能只做静态卡片加扫光。每条设计“触发 → 变化/冲突 → 结果”的完整过程，通常 3–4 个节拍，每 1.5–3 秒一次明显变化；同一时刻只突出一个动作。
- 动作演示类组合至少两种有语义联系的动作，例如物体输送+压缩、插头对接+能量流动、抓取转运+释放接收、失焦+光路调整+清晰显影、费用分流+汇集口袋。复杂度来自动作之间的因果，不来自粒子数量、满屏线条或更多说明字。
- 动作要有接触、受力/约束及完成反馈：抓爪接住物体才同步移动，放下后松开并回撤；液体从枪头进入容器；被阻挡的请求停在边界；流量分配有来源和去向；图表比例与数据一致。
- 至少一个记忆点：体积压缩、形态变换、机械锁定、跨空间接力、遮挡揭示或对比反转。动作有蓄势与收束，材质、遮挡、纵深和缓动一致；避免所有元素统一浮动。
- 连续两条不能仅复用同一图形结构并更换文案/图标。分镜表检查构图、机制、运动方向与节奏的变化，背景不同不能代替前景设计不同。
- 结论落定留出阅读时间；首帧已完整可用，尾部保持最终构图 12–18 帧直接结束，无片头片尾转场。

## 上下扫光与层序

固定顺序：背景图 → 暗化/氛围 → 上下扫光 → 主体动画/玻璃面板 → 标题及标签。

- 使用横向柔光带在画面中上下移动，一个素材可完成一次下行和回升，缓入缓出；如 y=220+(1-cos(2πt/T))*655，T 为实际运动时长，末尾进入 hold。
- 扫光必须位于背景和其他图层之间，不能覆盖文字、扫白面板或遮住主体；不是全屏擦除或转场。宽柔光为主，细光芯克制，不出现刺眼白闪。
- 背景单向推进不受扫光往返影响；不要给整个根场景套往返 CameraRig，导致字体与底图一起晃动。

## 渲染与验收

- 最终渲染 concurrency=1，本地背景/字体/音效，主要语义动作配轻音效，同帧不叠重音，素材无配音时明确注明。
- 先检查机器画面健康、字体落位、音效在场、格式；使用配方卡时按主技能保真检查。有声画锚点才做词级检查。
- 全批检查首帧、尾帧、每一动作落点与边界前后连续帧；不能以静态封面证明动作连贯。390px 宽复核：顶部主标题与二级标题恰好两行、无中间滚动说明、无撞字、无出界、背景独立、扫光层序正确。
- 独立新上下文评审最终 MP4 抽帧与动作关键区间；除主技能 P0/P1 外，重点判断不用中间说明文字能否理解动画，动作是否有因果和完成反馈。模板重复、只有卡片亮灭而无承诺的机制动作，须返修。
- 按主技能最多 3 轮修复复评；不得把未检查项目记为通过。
- 交付：20 条独立 MP4（或用户指定数量）、连看预览、封面总览、背景原图、口播对应表、提示词与来源记录，以及完整 ZIP；最终链接使用绝对路径。保留可复用工程，说明未配音/未逐字对齐等实际状态。
