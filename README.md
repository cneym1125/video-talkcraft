# video-talkcraft

一个只用于生成独立视频素材和 B-roll 的 Codex skill。

作者与维护者：**CNEYM1125**。

它把口播、文章或课程文案拆成一组可剪辑的视觉素材：每条素材有独立背景、顶部两行标题、清楚的前景动作和完整结果。背景使用 Codex 内置 `image_gen` 生成或编辑，文字使用本地阿里巴巴普惠体 3。

这个版本只保留素材规划与生成能力，不包含配音、字级时间戳、Remotion 成片、动效配方库、模板或演示画廊。

## 使用

把本仓库交给 Codex，然后说明：

```text
使用这个 skill，根据下面的文案生成独立视频素材：
<文案>
```

默认输出竖屏 1080×1920 素材。你可以指定数量、时长、画幅和视觉风格。

## 目录

- `SKILL.md`：素材生成规则与工作流程
- `references/cger-broll-standard.md`：独立素材详细标准
- `assets/fonts/`：本地字体文件
